# Yongxin Guan (Kevin) — Personal Homepage

Personal academic homepage of [Yongxin Guan](https://kevinyxguan.github.io/), a Data Science undergraduate at Beijing Normal-Hong Kong Baptist University (BNBU), interested in multimodal AI, world models, knowledge graphs, agents, and LLM systems.

Built with the [AcadHomepage](https://github.com/RayeRen/acad-homepage.github.io) template (Jekyll + GitHub Pages).

## Local Development

```bash
bash run_server.sh   # starts Jekyll server at http://127.0.0.1:4000
```

## Structure

- `_config.yml` — site and author configuration
- `_pages/about.md` — homepage content (bio, research, experience)
- `_data/navigation.yml` — navigation menu
- `images/` — avatar and favicons
- `files/` — CV downloads
